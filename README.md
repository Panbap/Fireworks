# 🎆 Fireworks Animation

> ✨ Hiệu ứng pháo hoa đẹp mắt được xây dựng bằng HTML, CSS và JavaScript.

🌐 **Live Demo:** https://panbap.github.io/Fireworks/

---

## 🚀 Giới thiệu

Đây là một project nhỏ mô phỏng hiệu ứng **pháo hoa** trên trình duyệt.  
Phù hợp để:
- Trang trí website 🎉
- Landing page / sự kiện 🎆
- Thực hành animation với Canvas / JS  

---

## ✨ Tính năng

- 🎇 Hiệu ứng pháo hoa mượt mà
- 🎨 Có thể tùy chỉnh màu sắc, kích thước
- ⚡ Nhẹ, chạy trực tiếp trên trình duyệt
- 📱 Responsive (chạy tốt trên mobile)

---

- JavaScript (Canvas / Animation)
